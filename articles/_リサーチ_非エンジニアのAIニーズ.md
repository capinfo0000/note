# リサーチ：非エンジニアが、AIで実際に"やりたいこと"は何か

連載「AI活用ピラー」（[[_コンテンツ計画]]）全体の土台調査。特定1記事用ではなく、L1（ツール選び）/L2（道具づくり）/L3（開発寄り）の各レーンで「実際に需要のある"やりたいこと"」を掴むのが目的。
過去ナレッジ（[[selling-patterns]]＝売れる型／[[reader-voice]]＝読者の声※現状空）を踏まえて作成。
**事実＝出典付き／推測＝「（推測）」と明記**で区別している。

---

## ① 職種・立場ごとの「やりたいこと」（作業レベル）

検索・記事事例から、非エンジニアが実際にAIにやらせている／やらせたい作業を職種別に整理。
（事実：複数の活用事例記事で繰り返し挙がる用途。出典は末尾）

### 事務・総務・バックオフィス
- **Excel/スプレッドシートの関数を「やりたいことを言うと作ってくれる」**（VLOOKUP・IF・ピボットの代わりにAIに数式を書かせる）
- 月別売上などの**集計表の構造ごと提案させる**／表データを貼って整理・分類させる
- 社内文書・お知らせ・規程のたたき台作成、文章の**敬語チェック・言い回し修正**
- 長文資料・PDFの**要約**、マニュアルの下書き
- 定型作業の手順書化、問い合わせ返信テンプレ作成

### 営業
- **議事録・商談メモの要約**（録音→文字起こし→要点・決定事項・次回アクション抽出）
- **営業メール・返信文・お礼文のドラフト**生成
- 提案書・企画書の**構成案／見出し案**作成、キャッチコピー案出し
- 顧客リサーチ・競合分析の初期調べ物、トークスクリプト作成

### 経理・財務
- 関数・計算式の作成支援、データ整理・分類
- 自然言語で家計／収支を相談し**改善案を出させる**（個人寄り）
- 規程・通知文の文面チェック

### 個人事業・副業
- **SNS投稿文・ブログ記事・キャッチコピー**の作成
- noteなど**有料コンテンツ・プロンプト集**の作成（後述、AI×収益化が一大ジャンル）
- **アイキャッチ画像・バナー・SNS画像**の生成（Canva×AI、ChatGPT画像）
- 商品説明文、LP文章、メルマガ作成

### 主婦・生活者
- **献立提案**（冷蔵庫の食材＋「30分以内」等の条件入力 → メニュー＆買い物リスト）
- 家事・掃除スケジュール、育児の相談、家計管理の相談
- 子どもの学習サポート、調べ物、文章の相談ごと

### 全職種横断で最頻出（事実）
活用事例記事で繰り返し上位に来るのは **①文章作成（メール・文書） ②要約・議事録 ③アイデア出し・たたき台 ④調べ物・リサーチ ⑤Excel/表計算**。これが"非エンジニアのAIの主戦場"。

## ② 検索・SNSの実需（裏取り）

実際によく検索／質問されている用途・悩み（事実：検索結果に多数の解説記事が存在＝それだけ検索需要があるテーマ）。

- **「ChatGPT エクセル 関数 作って」「ChatGPT Excel 自動化」** … 解説記事が大量。事務職の主戦場。
- **「ChatGPT 議事録 作成 / 文字起こし / 要約」** … 専用ツール比較まで派生する根深い需要。
- **「ChatGPT 仕事 活用事例」「業務効率化 アイデア」** … "そもそも何に使える?"の入口需要が最大ボリューム。
- **「主婦 ChatGPT 使い方 / 献立 / 家事」** … 生活者層の入口。Kindle本まで出ている。
- **「ChatGPT Claude Gemini Copilot 違い / どれがいい / 使い分け」** … 2026年も比較記事が量産され続ける＝**ツール選びの迷いは恒常的な需要**。
- **「AI 副業 おすすめ」「ChatGPT note 稼ぐ」** … 収益化系は検索・note内ともに過熱。
- **「生成AI 使われない / 定着しない / 何に使えばいいか分からない」** … 企業・個人ともに"導入したのに止まる"が大問題化（パーソル/SHIFT AI等が調査・記事化）。

→ 検索需要は大きく2層。**(A) "何に使えるか分からない"層（広い・浅い）** と **(B) 特定作業を解決したい層（狭い・深い＝Excel関数、議事録など）**。

## ③「やりたいこと」×「向くツール」の対応（"どのツールで何ができる"素材）

事実：2026年の比較記事群でほぼ共通する見解。

| やりたいこと | 向くツール | 理由（記事での評価） |
|---|---|---|
| 汎用・最初の1台・画像も1台で | **ChatGPT** | 万能・画像生成も内蔵・初学者向き |
| 自然な日本語の文章・長文要約・敬語の文書 | **Claude** | 「日本語が自然」「契約書チェック・長文読解」で最評価 |
| Gmail/スプレッドシート/ドキュメント連携・リサーチ | **Gemini** | Google Workspace直結。膨大資料からの知見抽出 |
| Word/Excel/Outlookの仕事を時短 | **Microsoft Copilot** | Office連携でビジネス時短に最適 |
| 画像・バナー・SNSアイキャッチ | **ChatGPT画像 / Canva AI / DALL·E** | 文章入力だけ・テンプレ豊富で初心者向き |
| 自分専用AI（指示を固定した道具） | **GPTs（ChatGPT）/ Gem（Gemini）** | プログラミング不要で自作可、Gemは無料開放済み |
| 簡単な業務ツール・Webアプリを作る | **Gemini Canvas / Gemini CLI / Claude（Code）/ GAS×AI** | 非エンジニアが15分でツール自作の事例あり（ソフトバンク） |

ポイント（推測含む）：読者は「結局どれ？」で止まりがち。**"1つに絞らず用途で使い分け"が比較記事の共通結論**＝ここを噛み砕くだけで価値になる。

## ④ つまずき・諦めポイント

事実（調査・記事で繰り返し指摘）＋（推測）。

- **「何に使えばいいか分からない」**＝最大の壁。ツールはあるが自分の業務と結びつかない（パーソル・SHIFT AI調査。約4割が「今は使っていない」）。
- **「業務の中で活用するイメージがつかめない」**で離脱。最初に可能性は感じても続かない。
- **プロンプトが書けない**／「プロンプトが大事と言われても何を書けば…」。ただし最新の論調は「複雑なテンプレより、シンプルに投げて対話で育てる」に寄っている。
- **精度・ハルシネーションへの不安**（議事録など事実が絡む用途で特に。人の最終チェック必須が共通注意）。
- **ツール選びで止まる**（ChatGPT/Claude/Gemini/Copilotどれ？課金すべき？）。
- **(推測)** 「やってみたが思った答えが返らず、自分が悪いのか諦める」→ 一度の失敗で離脱しやすい。
- **(推測)** 道具づくり（GPTs/アプリ）は"自分には無理"という心理的ハードルが高い。

→ 諦めの本質は「能力不足」ではなく **"自分の仕事のどこに、どう当てるか"の翻訳ができないこと**。ここが記事の最大の刺さりどころ。

## ⑤ 有料note化しやすい用途／しにくい用途

事実（noteの価格相場・売れ筋分析）＋[[selling-patterns]]の知見＋（推測）。

### しやすい（お金を払ってでも解決したい深い悩み）
- **特定作業の"完成された型"**：議事録要約・営業メール・Excel関数生成の**そのまま使えるプロンプト/手順**（再現性が価値）。
- **"自分用の道具を作る"全手順**（GPTs/Gem/小さなアプリ）＝L2/L3。手順＋失敗談＝独自性が出しやすい。
- **Before→After実体験**（型A）。「ほぼ初心者がここまでできた」証拠。第1弾が92点で当たった路線。
- **収益化に直結する用途**（AIでnote/SNS/副業）＝財布の紐が緩い。ただしレッドオーシャン。

### しにくい（無料で十分／単価が乗りにくい）
- 「ChatGPTとは」「使い方の基本」など**一般論・初歩**（無料記事・公式・大手メディアで埋まっている）。
- 献立・家事など**生活ライフハック**単発（無料情報が豊富。集客・入口にはなるが有料は弱い）。
- ツール比較**だけ**の記事（無料で量産済み。ただし"使い分けの判断軸＋実体験"なら入口集客に最適）。

### note価格相場（事実）
- 300〜500円＝小ネタ集／980円前後＝副業ノウハウ・スキル系／1,500〜3,000円＝体系的教材・テンプレ付き／5,000円以上＝成功事例・体験。
- プロンプト集は**500〜1,000円が売れやすい**（初回購入の心理ハードルが低い）。
- 高単価でも売れるのは**実績・具体的成果がある人**。初心者はまず信頼構築と販売実績づくりが先。

## 連載への示唆（L1/L2/L3 別テーマ案）

過去の当たり（[[非エンジニアのAI活用術]]＝L2・92点：原体験ストーリー）を軸に、需要×差別化で配置。
**発信者の武器＝「非エンジニア寄りだが現場で実際にAIで道具を作った経験」**。一般論を避け、経験者しか書けない切り口を必ず混ぜる。

### L1（ツール選び・無料寄り・集客）
1. **「結局どのAIを使えばいい？"やりたいこと別"使い分けガイド」** … ④の迷いに直撃。比較は飽和だが「用途→ツール」の翻訳表＋"自分はこう使い分けている"実体験で差別化。**入口集客の旗艦**。
2. **「ChatGPTで"何に使えばいいか分からない"を終わらせる｜職種別・最初の3タスク」** … 最大ボリュームの悩み(B層の手前)を拾う無料記事。事務/営業/個人で具体作業を提示。

### L2（非エンジニアの道具づくり・有料）
3. **「議事録/メール/Excelを"毎回ラクにする"｜AIで作る自分専用プロンプト＆GPTsの作り方」** … 最頻出作業×再現性。①②の主戦場をそのまま型化。有料の本命。
4. **「非エンジニアが15分で業務ツールを自作した話｜Gem/GPTsで"自分の面倒"を消す全手順」** … ソフトバンク事例で需要実証済み。第1弾の続編動線。Before→After（型A）×手順（型B）。

### L3（開発寄り・有料・指名買い）
5. **「AIにちゃんと伝わる指示・設計の出し方｜"動かない・的外れ"を抜けた実務の具体例」** … ④のプロンプト挫折を、現場で効いた型で解決。第1弾の第3〜5章深掘り（計画の既存案を裏付け）。

---

## リサーチ総括
非エンジニアのAI需要は明確に2層。**(A)「何に使えるか分からない」広く浅い迷い**（→L1で無料集客）と、**(B) 議事録・メール・Excelなど"特定作業を毎回ラクにしたい"深い悩み**（→L2で有料化）に分かれる。
有料で勝てるのは一般論ではなく、**「特定作業の再現できる型」＋「非エンジニアが実際に道具を作った実体験(Before→After)」**。発信者の「現場でAIで道具を作った」経験は、まさにこのB層・L2の本命に直結する最大の武器。
攻め順は **L1で"やりたいこと別ツール使い分け"＋"職種別・最初の3タスク"で母数を集め → L2(議事録/メール/Excelを自分専用化、ツール自作)で有料化 → L3(指示・設計の型)で続編販売**。ツール比較や家事ハックは無料・入口に留め、有料は「経験者しか書けない手順と失敗談」に絞るべき。
