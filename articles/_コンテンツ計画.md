# コンテンツ計画（AI活用ピラーの連載地図）

発信ブランド：20代一人暮らしエンジニアのリアル（節約／投資／AI）。
このファイルはその中の **AI活用ピラー** の連載計画。1記事1ターゲットで「軸のぶれ」を消す。
新しい記事を作るときは [[researcher]]→[[planner]]→[[writer]]→[[editor]] に、ここで決めたターゲットと軸を渡す。

## 軸の分け方（読者で3レーン）
| レーン | 読者 | 求めるもの | ツール軸 |
|---|---|---|---|
| **L1 初心者・ツール選び** | AI気になるけど何から？ | どのツールで何ができるか・使い分け | ChatGPT/Claude/Gemini/Copilot 横断 |
| **L2 非エンジニアの"道具づくり"** | 仕事をラクにしたい非エンジニア | 自分用の小さな道具を作って効率化 | ChatGPT〜Claude Code |
| **L3 開発寄り（駆け出し）** | 自分でアプリ/システムを作りたい | 指示・設計・検証の具体的なやり方 | Claude Code 中心 |

## 連載ラインナップ

### ✅ 第1弾（完成・92点）：`非エンジニアのAI活用術/`
- レーン：**L2**（自分用の道具を作って仕事をラクに）の旗艦＝原体験ストーリー
- ターゲット：ChatGPT触ったけど止まってる非エンジニア
- 役割：「ほぼ初心者でもAIで実際に道具を作れた」という証拠で、読者を勇気づける入口記事
- ※この記事は L2 に確定。タイトル/第1章の「実務システム」感は"証拠"として残す

### 📝 次の候補
- **L1-1：「結局どのAIを使えばいい？用途別・使い分けガイド」**
  - 読者：何から触ればいいか分からない初心者
  - 切り口：このツールはこれが得意／他のツールとの違い・使い分け（"どのツールで何ができる"）
  - 売れる型：B（ノウハウ抽出）。無料記事で母数を集める入口にも向く
- **L3-1：「AIにちゃんと伝わる指示・設計の出し方（実務で効いた具体例）」**
  - 読者：作りたい駆け出し・もう一歩踏み込みたい人
  - 切り口：第1弾の第3〜5章をさらに深掘り。指示の型／壁打ち設計／出力の検証を具体例で
  - 売れる型：A×B。第1弾からの動線（続編）にできる
- **L2-2：「今日できる、身近な作業をAIで自動化する最初の1個」**
  - 読者：第1弾を読んで「やってみたい」と思った人
  - 切り口：第6章を1記事に拡張。手順を最小単位で。再現性重視

## 運用メモ
- 各記事は単独で完結させつつ、末尾でレーンの別記事へ自然に内部リンク（回遊）
- L1は無料寄り（集客）、L2・L3は有料に向く
- 作った順に上の「次の候補」を「完成」へ移し、`results.md` に結果を記録
