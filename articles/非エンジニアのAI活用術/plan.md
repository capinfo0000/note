## ①【記事テーマ・コンセプト】

**一言でいうと（30文字以内）**
> ほぼ初心者の自分がAIで実務システムを1ヶ月で作った全記録。

**読者のビフォー → アフター**
- ビフォー：ChatGPTやClaudeを触ってはみたが「思った答えが返らない」「結局自分の手元では何も動かせない」状態で止まっている。周りがAIで効率化していく中、取り残される焦りだけが募っている。
- アフター：「専門家じゃない自分でも、AIを"指示の出し方"と"出力の見抜き方"さえ押さえれば、実務で使える小さなツールを作れる」と確信し、最初の一歩（自分の業務の一部をAIに任せる）を今日踏み出せる状態になる。

**なぜ今この記事を出すべきか（市場タイミング）**
- 「バイブコーディング」が2025年Collins英語辞書のWord of the Year、MIT Technology Reviewの2026年10大ブレークスルーに選出。"コードを書かずに作る"が一般語化し、非エンジニアの関心が急騰中（research①）。
- 2026年3〜4月にClaude Codeがブラウザ版対応＝ターミナル不要になり、「今なら自分にもできそう」という気運が最高潮（research①）。
- 一方で「AIで仕事がなくなる」不安も併存し、"使われる側でなく使う側に回りたい"焦りが購買動機になっている（research①）。
- 無料の「プロンプト基本」「活用○選」は飽和（レッドオーシャン）。等身大の実体験×つまずきの抜け方を体系化した有料記事はまだ薄い＝今が空白の旬（research⑦）。

## ③【タイトル案】（4要素：誰に／どんな価値／どんな内容／どう伝えるか を全案に）

1. **「プログラミングは無理」と思っていた僕が、AIで実務システムを1ヶ月で作るまでの全記録**
   → 読者と同じ"無理だと思っていた地点"から始まる体験談で、ビフォー→アフターが一目で伝わる（型A直撃）。

2. **ChatGPTを触ったけど何も作れなかったあなたへ｜AIで"自分専用ツール"を動かす最初の一歩**
   → 「触ったけど止まっている」読者をピンポイントで名指し、得られるもの（動くツール）を明示。

3. **AIに丸投げして失敗する人と、戦力にできる人の分かれ道｜非エンジニアのための実践ガイド**
   → 競合が書けない核（鵜呑み・丸投げの落とし穴）を意外性のあるフックにした、差別化型タイトル。

4. **ターミナルもGitも怖かった僕が、AIで業務を自動化できた理由｜つまずき7つと抜け方**
   → 読者の恐怖ポイント（ターミナル/Git）を代弁＋「7つ」の数字で具体性と完結性を演出。

5. **「AIで効率化した」に取り残されたあなたへ｜ほぼ初心者がClaude Codeで実務を変えた話**
   → 焦り（緊急性・共感）を起点に、トレンドKW「Claude Code」を入れて流入も狙う。

> 推奨：**第1案**をメインに。理由＝型A（経験のリアル）が最も再現性が高く、"ほぼ初心者"という立ち位置の指示と完全一致するため。サブで第2案（ターゲット名指し）を併用検討。

## ④【記事の構成案】

### 無料パート（章立てしない・1,500〜3,000字）
目的は「この続きを買わなきゃ」と思わせることだけ。具体的なノウハウ・手順は一切出さない。

1. **共感（あなたもこうじゃないですか？）**
   - 「ChatGPTを触ってはみた。でも"で、結局これ仕事の何に使えるの？"で止まっていませんか」
   - 同僚は時短してるのに自分だけ実感ゼロ、取り残される焦り。ノーコードAIもエラーで放置した――を代弁する。
   - `【要・実体験】`：発信者自身が最初にAIに触ったとき「思った答えが返ってこなくて放置した」失敗があれば、ここに同じ目線で置く。

2. **問題の本質を突く（実はその悩み、○○が原因）**
   - 「動かせないのは、あなたの能力やセンスのせいじゃない。"指示の出し方"と"AIの出力を見抜く目"を誰も教えてくれなかっただけ」と本質を突く。
   - 巷の「プロンプト集」「活用○選」を読んでも自分ごとに落ちない理由を言語化する。

3. **希望を見せる（でも、○○すれば変わる）**
   - 「実は僕も、つい最近まで"ほぼ初心者"でした」と等身大で明かす。
   - `【要・実体験】`：**それでもAIを使って、約1ヶ月で見積・請求書システムをほぼ1人で実運用化できた**――という事実を、自慢でなく「初心者でもここまでできる証拠」として軽く提示（詳細は有料へ）。具体数字（期間・1人で・何を作ったか）を1〜2行だけ見せる。

4. **有料パートへの橋渡し**
   - 「ここから先で、僕が何でつまずき、どう抜けたのか――"指示の出し方"も"出力の見抜き方"も、丸投げで事故らないための判断基準も、全部順番に渡します」
   - 「今日のうちに、あなたの業務の一部をAIに任せる最初の一歩が踏み出せるように書きました」で締めて、購入の直前まで温度を上げる。

> 区切り：`【ここから有料パート】`

### 有料パート（第1章〜第7章・6,000〜12,000字／基礎→応用）

**第1章：そもそも、ほぼ初心者の僕が何をどこまで作れたのか（全体像とビフォー→アフター）**
→ この章を読めば「自分にもできそう」という現実的なゴールイメージが持てる。
- `【要・実体験】`：触り始めた頃の自分のレベル感／約1ヶ月で作った見積・請求書システムの中身（インボイス対応・PDF/CSV出力・集計・承認など）を、非エンジニアにも伝わる言葉で。"何ができるようになったか"を先に見せる。

**第2章：最初の壁を越える｜ターミナル・Git・APIキーが怖くなくなる安全な始め方**
→ この章を読めば、恐怖で止まっていた手が動き出し、最初のセットアップを越えられる。
- `【要・実体験】`：自分が最初に何にビビったか／ブラウザ版で始める等、怖い言葉を避けて踏み出した具体ルート。

**第3章：AIに思い通り動いてもらう指示の出し方｜的確な答えが返る伝え方の型**
→ この章を読めば、「思った答えが返らない」が「狙った答えが返る」に変わる。
- `【要・実体験】`：自分が"返ってこなかった指示"→"返るようになった指示"のビフォーアフター実例。コピペで使える指示の型を渡す（B型の核）。

**第4章：AIの出力を鵜呑みにしない技術｜"それっぽく間違える"を見抜く目【差別化の核】**
→ この章を読めば、AIの嘘・思い込みに騙されて事故る前に止められるようになる。
- `【要・実体験】`：実務で「AIが堂々と間違えた」具体例と、それをどう見抜き・どう直したか。競合がほぼ書けない現場知。

**第5章：丸投げして失敗する人と、戦力にできる人の分かれ道｜任せる範囲の決め方【差別化の核】**
→ この章を読めば、どこまでAIに任せ、どこは自分が判断するかの線引きができる。
- `【要・実体験】`：設計判断を丸投げして詰まった失敗／"ここは人間が決める"と切り分けた判断基準。

**第6章：自分専用ツールを作ってみる｜非エンジニアが本当に欲しい小さな自動化の実例**
→ この章を読めば、明日から自分の業務の一部をAIに任せる具体イメージが持てる。
- `【要・実体験】`：VBAでExcel作業をボタン化／集計ツール自作など、再現性の高い小さな実例を手順込みで。

**第7章：ハマった時の脱出法とまとめ｜止まらないための運用術と、あなたの次の一歩**
→ この章を読めば、つまずいても自力で抜け出せ、今日からの行動が決まる。
- `【要・実体験】`：実際にハマった時にやった脱出手順（リスト化）／向き不向きの判断。最後に「まずこの1つから始めよう」という次のアクションで締める。

## ⑤【差別化ポイント】

**この記事にしかない強み**
- 「現役エンジニアが、わざと専門用語を使わず、元・初心者の目線で教える」二刀流。"実務で戦力にしているが、自分でもほぼ初心者の気持ちが分かる"立ち位置は競合に真似できない（research⑦）。
- **約1ヶ月でほぼ1人で実務システムをリプレイスした一次情報**。期間・1人で・実装機能という代替不能な数字と、その過程のつまずき・判断（型A×B）。
- 競合が書かない核を正面から扱う：**第4章「AIの出力を鵜呑みにしない技術」**と**第5章「丸投げ／戦力の分かれ道」**。素人が最も事故る落とし穴を、現場知で抜け方ごと言語化する。

**なぜ他ではなくこの記事を選ぶべきか**
- 「活用○選」の薄いまとめでも、専門家の自慢話でもない。「自分と同じ地点から始めた人が、つまずきも含めて全部見せてくれる」唯一の道案内だから。

**独自フレームワーク（記事内で使う切り口）**
- **「丸投げ⇄戦力」の分かれ道マップ**：AIに任せて事故る行動／戦力にできる行動を対比で整理（第5章）。
- **「鵜呑み防止チェックリスト」**：AIの出力を信じる前に確認する数項目（第4章）。読者が"資産"として持ち帰れる形にする。

## ⑥【価格設定の提案】

- **推奨価格：680円**（500〜980円ゾーン）。
- 根拠：実績ゼロの1本目は `selling-patterns.md` の指針通り、まず低〜中価格で**"買われる体験"を取る**のが最優先。一方で実体験という強い一次情報＋コピペできる指示の型・チェックリストという"資産"があるため、ワンコインの500円より少し上げ、価値とのバランスで680円が妥当。反応を見て2本目以降は1,500円超も狙える。
- **無料／有料の境界線**：上記④の無料パート「4. 有料パートへの橋渡し」直後、第1章の手前に `【ここから有料パート】` を置く。無料側には"何を解決できるか・どこまで作れたか"の事実は見せるが、"どうやるか（指示の型・見抜き方・手順）"は一切出さない。
