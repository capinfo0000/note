# 発信者プロフィール（社長の分身データ）

このファイルは発信者本人の「中身」。writer / editor / promoter は執筆前に必ず読み、
ここにある経歴・実体験・価値観を記事に反映すること。一般論ではなく「この人だから書ける」記事にする。

> ⚠️ まだ記入途中（発信者へのヒアリングで埋めていく）。空欄を勝手に創作で埋めないこと。
> 🔒 このファイルはGit管理下。**本名・会社名/勤務先名・住所・電話番号・メール・給料/年収は書かない**
>    （活動名はOK、株/ビットコイン/資産の金額はOK）。実名等が必要なら `_private/` に置く。
>    経歴は「前職（ある企業）」「都内」のように、所属が特定されない粒度で書く。

## 基本
- 活動名（本名は書かない）：
- 年代・属性：
- 現在の仕事・活動（業種/職種で。会社名は書かない）：

## 経歴（ストーリーの素材）
- これまでの経歴（時系列で。転機・失敗・挫折・回復を特に。固有名はぼかす）：
- 今の仕事に至った理由：
- 誇れる実績・数字（給与額以外。資産・売上規模などはOK）：

## 専門・強み（記事のネタ源）
- 専門分野・得意領域：
- 現場でしか分からない知見・あるある：
- 人によく聞かれること・教えてきたこと：

## 興味関心・価値観
- 好きなこと・没頭していること：
- 大事にしている考え方・信条：
- 嫌いなこと・絶対にやらないこと：

## 発信スタンス
- 誰に届けたいか（理想の読者像）：
- どんな存在として見られたいか（先輩 / 専門家 / 仲間 など）：
- 言いたくないこと・触れてほしくないNGテーマ：
