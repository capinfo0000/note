## 発信スタンス
- **発信の主軸（人物ブランド）：20代・一人暮らし・エンジニアのリアル（節約／投資／AI活用）**
  - アカウント全体の人物像は「等身大の20代一人暮らしエンジニア」で広く取り、共感で母数を集める
  - ただし1本1本の記事は「特定の1人の具体的な悩み」に狭く絞る（広く構えて、各記事は深く）
- **テーマ別の役割（収益化マップ）**：
  - 💰 AI活用（実務リアル）… 有料の主力。現役でClaude Codeを実務投入している差別化
  - 💰 投資・資産形成 … 有料いける。★株/暗号資産/資産額は記載OKなので「自分の数字を出せる」のが強み（※給料/年収はNG）
  - 📣 節約・一人暮らし … 集客・共感（無料向き）。等身大で母数を集める
  - 📣 エンジニア転職のリアル … 集客・共感。複数業界を渡り歩いた経験
- 戦略：節約・一人暮らしで共感を集め → AI活用・投資で収益化、の二段構え
- どんな存在として見られたいか：一歩先を行く実践者／同じ目線で試行錯誤している仲間（ベテラン専門家ぶらない）
- NGテーマ：**【要確認】**（※本名・社名・住所・連絡先・給料/年収は全テーマ共通で記載不可）
