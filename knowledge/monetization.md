# noteの収益化方法（販売形態の引き出し）

planner / 社長AI が「どう売るか（販売形態）」を判断するための地図。
有料記事1本だけが収益化じゃない。読者との関係の深さ・段階に合わせて手段を選ぶ。

> ※出典の補足：参考にしようとしたCanvaの記事（how-to-monetize-note）は
> Cloudflareのボット対策で自動取得できなかった。以下はnote公式機能の確立した知識ベース。
> 各機能の最新の利用条件（解放条件など）は、実際に使う前にnote公式で要確認。

## 収益化の手段（浅い関係 → 深い関係）
| 手段 | 中身 | 向く場面 |
|---|---|---|
| **サポート（投げ銭）** | 記事を気に入った読者が任意で送金 | 無料記事でファンが付いてきた段階の入口 |
| **有料記事（単体）** | 1記事を有料販売（本リポジトリの基本） | 1本完結のノウハウ・体験談。まず実績を作る |
| **有料マガジン（束ね売り）** | 複数の有料記事をまとめて1つの価格で | 関連記事が溜まったら束ねて単価UP（連載と相性◎） |
| **定期購読マガジン（月額）** | 毎月課金で継続的にコンテンツ提供 | 定期発信が習慣化し、継続して読みたい人がいる段階 |
| **メンバーシップ（月額コミュニティ）** | 月額の会員制。限定記事＋交流の場 | ファンが増え、双方向の関係を作れる段階 |
| **お題・コンテスト参加** | 直接収益でなく露出・流入を稼ぐ | 初期の認知拡大。集客の補助 |

※サポート/有料記事は始めやすい。マガジン・定期購読・メンバーシップは「記事や読者が溜まってから」効く（順番が大事）。

## このブランドでの使い方（連載と接続）
`articles/_コンテンツ計画.md` の攻め順（L1集客 → L2有料 → L3続編）に重ねると：
1. **まず単体の有料記事**で「売れる体験」と実績を作る（＝今やっていること）
2. レーンごとに記事が溜まったら **有料マガジン**で束ねて単価UP（例：「非エンジニアのAI活用」マガジン）
3. 継続発信が回り、固定ファンが増えたら **定期購読 or メンバーシップ**で月額収益（ストック化）
4. 無料記事＋**サポート**＋お題参加で、入口（集客・投げ銭）を広げる

## 値付けの基本（`selling-patterns.md`と整合）
- 1本目の単体記事：実績作りで 500〜980円（まず買われる体験）
- 体系的・再現性の高い教材級：1,500〜3,000円
- 束ね（マガジン）：単体合計よりお得感を出しつつ、1本あたり単価を上げる
- 高単価は「実績・信頼」が前提。最初から高くしない

## 運用メモ
- 収益化の前提は結局「流入（X等の導線）」と「信頼（無料記事の実績）」（selling-patterns の売れない3大原因）。手段を増やす前に、まず母数と信頼を育てる。
- 新しい販売形態を試したら結果を `results.md` に記録して、効いた/効かなかったを蓄積する。
