## サムネ（見出し画像）の勝ちパターン ※note「#AI」人気記事をPlaywrightでライブ巡回して分析
note上で埋もれず読まれるサムネの型（Canva生成時のプロンプト指針にも使う）。基本は横長16:9、AI生成画像が非常に多い。

### よく見る4タイプ
1. **AI生成イラスト（キャラ・動物）**：彩度高め・親しみやすい。テキストを焼き込むことも多い（例：走るパンダ＋「悔しさをバネにしよう！」）
2. **文字主役のデザインサムネ**：大きな日本語タイトル＋人物。ビジネス・株・マーケ・情報系の定番（例「明日からの株式市場どう見る？」）← **うちのAI/お金/エンジニア系はこれが本命**
3. **写真風・幻想的ビジュアル**：リアル寄りの質感。エッセイ・思索系記事
4. **ミニマル／白背景＋テキストのみ**：情報量を絞って差別化。シンプルで目を引く

### 効くポイント（実観察）
- **タイトル文字をサムネに焼き込む**のがビジネス系で定番＝読む前に内容が伝わる（クリック前に価値が分かる）
- **人物、特に"表情のある顔"**を入れると反応が良い
- **暖色・高彩度**のイラストが伸びやすい
- **キャラ/動物イラスト＋ポジティブな一言**の組み合わせが反応を集めやすい
- 共通点＝**サムネ単体で内容・トーンが一目で伝わる**こと

### タイプ⑤：投資・情報系インパクト型（お金/投資レーンの本命）
発信者が「こういうの作りたい」と挙げた、note投資ジャンルの王道スタイル：
- 高彩度のアニメ美少女（驚き/ワクワク顔・大きい瞳）を右に配置
- **金×赤×黒の極太装飾テキスト**（金グラデ＋黒フチ＋赤アクセント、光エフェクト）
- 数字を巨大に（資産額・指数など）、黒帯に白抜き、煽り強め
- 末尾に【○○の○○論】＝発信者ブランド名で締め（要・活動名）
- 作り方：ChatGPTで「キャラ＋ドラマチック背景（文字なし）」生成→Canvaで装飾テキスト載せ（日本語装飾は画像生成では崩れるため必須）
- 相性：💰お金・投資レーンに最適。AI/誠実系記事には装飾だけ流用し煽り文句は抑える

### サムネ生成プロンプト雛形（ChatGPT等の画像生成用・タイプ②）
```
横長16:9のnoteアイキャッチ。情報・ビジネス系noteで伸びる「文字主役＋人物」型。
クリーンで親しみやすく前向き、テック感は控えめ、高コントラストでスマホでも読める。
左に大きな日本語見出し（極太ゴシック）＋キーワードを赤/黄で強調、右に等身大の会社員（オフィスカジュアル）、
背景は白〜淡色のシンプルグラデ＋AIアイコン控えめ。配色は青基調＋赤/黄アクセント。
```
※AI画像生成は日本語が崩れやすい。崩れる場合は「文字なし＋左に余白」で生成し、文字はCanvaで載せるのが確実。
※用途別に差し替え：見出し文、人物、強調キーワード。

### うちの方針
- AI活用/お金/エンジニア系の記事は **タイプ②（文字主役＋人物）** を基本に。大きい見出し＋キーワード色強調（赤/黄）。
- 共感・ライフ系（節約・一人暮らし）は **タイプ①（高彩度イラスト＋ポジティブ一言）** も有効。
- 制作はCanva（MCP連携）で生成→候補から選ぶ→保存。実際の巡回はローカルのPlaywright MCPで（このWeb環境はブラウザ不可）。
