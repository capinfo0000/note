# 販売実績ログ（売れる目を育てる記録）

記事を出すたびに1行〜数行で追記。AI（researcher/planner）はここを読んで「過去に何が当たったか」を踏まえる。
数字が出る前は「仮説」でもよい。後で結果を追記して、仮説の当たり外れを残すと一番学びになる。

## テンプレ（コピーして使う）
```
### YYYY-MM-DD [[記事フォルダ名]] ＜記事タイトル＞
- ジャンル/テーマ：
- 価格：
- ターゲット（1人）：
- 結果（PV / スキ / 購入数 / 売上）：
- 効いた要因（仮説）：
- イマイチだった点・次への改善：
```
※ `[[記事フォルダ名]]` のようにObsidianのリンクで書くと、グラフ上で記事と実績がつながる。
