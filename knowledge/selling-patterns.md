# 売れるnote記事の型（実データ分析）

実際に売れているnote有料記事の分析（note編集部500件分析／第三者の200記事調査ほか）から抽出した「売れる法則」。
**researcher / planner / writer / editor はこれをチェック視点・設計指針として使う。**
（出典は末尾。蓄積が増えたら自分の `results.md` の実績で上書き・補強していく）

## 結論：売れない原因は「実力不足」ではなく「設計不足」
内容の濃さより「伝え方の設計」が整っているかで決まる。売れない3大原因＝①流入がない ②実績/信頼がない ③無料部分が弱い。

## 売れる記事の3つの型（どれかに当てはめる）
| 型 | 中身 | 向く人 |
|---|---|---|
| **A：経験のリアル型** | Before→Afterが明確。「自分も変われるかも」と思わせる体験談 | 初心者ターゲット向け・最も再現性が高い |
| **B：ノウハウ抽出型** | 実践ハウツーの体系化＋独自データ（一次情報） | 中級者ターゲット向け |
| **C：視点・思想型** | 独自ポジション・切り口でファンを作る | 上級者・指名買い向け |

→ 専門・仕事の知識ジャンルなら **B（ノウハウ抽出型）に自分の実体験（A要素）を混ぜる**のが強い。

## タイトル設計の4要素（500件分析）
1. **誰に向けた内容か**（対象者を明確に。例：副業初心者向け）
2. **どんな価値があるか**（ベネフィット。例：3ヶ月で初収益）
3. **どんな内容か**（具体。例：文章術の基本）
4. **どう伝えるか**（型。例：体験談／3ステップ形式）

共通する3特徴＝**具体性・読者メリットの明示・トレンド性**。

**避けるタイトル**：曖昧／対象者不明／抽象語だけ／一般的すぎ／メリット未表記。

| 弱い | 強い |
|---|---|
| 副業で稼ぐ方法 | 会社員が週末2時間だけで月3万円を稼いだ、初心者向けnote運営の全手順 |
| ChatGPTを使ってみた | ChatGPTで仕事が10倍速に｜実際に役立った活用法5選 |
| 最近思ったこと | 続かない日でも書けた、私の文章習慣の整え方 |

## 無料部分の黄金法則
役割は「信頼の醸成」だけ（ノウハウは出さない）。冒頭で必ず：
- 読者の悩みを鮮明に**言語化して代弁**する（「これ自分のことだ」）
- 「このままではまずい」危機感 or「こうなりたい」希望を喚起
- この記事に解決策がある／書き手は信頼できる、と示す
- 「有料部分にはもっと具体がありそう」と期待値を作る

## 有料部分・差別化
- 売れる/売れないの差は**独自性**。実体験・失敗談・成功までのプロセス・独自の評価基準＝そのまま価値。
- 「どうすればいいか」の**具体的手順**を必ず提示。抽象論で終わらない。
- 一次情報（自分で取ったデータ・自分の数字）を混ぜると強い。

## ターゲット
絞ると市場が狭まる気がするが逆。「これは自分のことだ」と感じた読者の購買意欲が跳ね上がる。**1人に絞る**。

## 価格・その他
- 初心者は低価格帯（数百円〜）の実績例が多い（¥398等）。まず「買われる体験」を取る。
- 流入（X等の導線）と実績（無料記事での信頼）が無いと、良い記事でも売れない。
