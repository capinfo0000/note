# トレンド・ネタ供給ログ（バズ候補の記憶）

発信者がトレンドに乗った記事を作れるようにするための「ネタ供給」ファイル。
researcher が定期的に更新。**最新を上に積む**。発信ブランドの3レーン軸の中だけを拾う（軸外は推さない）。

- L1：AI初心者・ツール選び（集客寄り）
- L2：非エンジニアの"道具づくり"（有料の主力）
- L3：開発寄り・駆け出し（Claude Code中心／有料）
- お金（投資・節約・一人暮らし／投資は有料、節約は集客）
- キャリア（エンジニア転職・働き方／集客・共感）

各ネタ：何がホットか／なぜ今か／裏取り／競合度／強みの乗せ方／レーンとタイトル案／賞味期限。
※「事実（裏取り済み）」と「推測（researcher所見）」は明記して区別する。

### 【L3 / 有料】① バイブコーディングの「修正地獄（Vibe Fixing）」を実務目線で
- **何がホット**：vibe coding（自然言語でAIに作らせる開発）。だが2026年は熱狂の裏で**「Vibe Fixing＝勢いで作ったコードの修正に、構築以上の時間がかかる修正地獄」**が語られ始めた。
- **なぜ今**：Karpathy提唱（25年2月）→ Collins英辞典「2025 Word of the Year」→ MIT Tech Review「2026の10大ブレークスルー技術」。話題のピークと"幻滅期入り"が同時に来ている。出典: [renue](https://renue.co.jp/posts/vibe-coding-ai-development-guide-2026) / [Felo](https://felo.ai/ja/blog/vibe-coding-guide-2026/) / [IBM](https://www.ibm.com/think/topics/vibe-coding)
- **競合度**：「バイブコーディングとは」の入門解説は**飽和（レッドオーシャン）**。だが「作った後どうメンテするか／設計を人間が握る話」は**穴場**。
- **強みの乗せ方**：E3（設計丸投げで半分作り直し）、E1（コアは1ヶ月、その後も追加要望で育て続けている＝まさに修正フェーズ）、E2（端数処理の検算）が一次情報として直結。「バズる作り方」でなく「**作った後に死なないための設計**」を経験者として語れるのが他と違う。
- **タイトル案**：「『バイブコーディングで作りました』の後に来る地獄｜実務で1ヶ月かけて作ったシステムを"今も育てている"私が学んだこと」／「AIに丸投げして半分作り直した話｜vibe codingで失敗しない設計の握り方」
- **賞味期限**：しばらく使える（半年〜1年）。幻滅期の議論はこれから深まる。

### 【L2 / 有料】② ChatGPTエージェントモードで非エンジニアの定型業務を代行
- **何がホット**：ChatGPTの**エージェントモード**が外部サイト・業務システムを人間の代わりに操作（会計ソフトから売上DLなど複数ステップを自動完了）。「指示する」から「設定したら自律で動く」フェーズへ移行。
- **なぜ今**：2025〜2026にかけ業務効率化AIが自律エージェント化。Difyなどノーコードで非エンジニアもフロー自動化が可能に。事例: 「非エンジニアが2日でAIアプリ、300分→15分」。出典: [経営デジタル](https://keiei-digital.com/column/ai-agent/chatgpt-agent/) / [Web担](https://webtan.impress.co.jp/e/2026/04/21/52383)
- **競合度**：ツール紹介・比較記事は**飽和**。「自分の具体業務にどう当てるか（翻訳）」は**穴場**（コンテンツ計画の"翻訳ができない"課題と一致）。
- **強みの乗せ方**：E4（VBAで図形挿入ボタン化・Excel集計半自動）、E10（営業時代のヒアリング力→何を自動化すべきか見極め）。「賢い機能の紹介」でなく「**自分の手作業のどれをエージェントに渡せるか**」を等身大で。
- **タイトル案**：「ChatGPTエージェントに毎週の"あの作業"を丸ごと任せた話｜非エンジニアが最初に自動化すべき1個の見つけ方」
- **賞味期限**：しばらく使える。機能名は変わっても「定型業務の代行」需要は続く。

### 【AI×お金 / 有料】③ ChatGPTの「家計・資産管理機能」をエンジニア目線で検証
- **何がホット**：**事実**＝OpenAIが2026年5月15日、ChatGPTに**個人向け資産管理機能**をプレビュー公開（米Proユーザー先行）。1.2万以上の金融機関と連携、支出・サブスク・投資成績・ポートフォリオをダッシュボード化、財務データを踏まえて相談できる。「記録する家計簿」から「AIと対話して改善する家計管理」へ。出典: [ITmedia](https://www.itmedia.co.jp/news/articles/2605/16/news027.html) / [Impress Watch](https://www.watch.impress.co.jp/docs/news/2109258.html)
- **なぜ今**：リリース直後で日本未提供＝「先取り解説」需要が立つタイミング。お金×AIの交差点で、当ブランドの収益2本柱（AI活用＋投資・資産形成）が交わる。
- **競合度**：「ChatGPTで家計簿」の汎用ハック記事は増加中だが、**新機能×セキュリティ実務目線**はまだ少なめ＝**やや穴場**。
- **強みの乗せ方**：E2（AIがお金の計算をそれっぽく間違える→検算の習慣）が刺さる。「口座連携は便利だが、AIの数字を鵜呑みにしない」を、システムを作る側＝検算を知る側として語れる。資産額を出せる強み（株/暗号資産はOK）も使える。
- **タイトル案**：「ChatGPTに口座を繋ぐ前に知っておくこと｜AIの家計管理を"作る側"が本気で検証した」／「AIに家計を任せてみた結果｜便利だけど絶対に自分で検算すべき場所」
- **賞味期限**：日本提供開始までは先取りネタ。提供後は実検証ネタに切り替え（半年〜継続）。

### 【L3 / 集客→有料】④ 「アプリ作りました」はもう無価値、価値ある実績とは
- **何がホット**：note上で**「AIで『アプリ作りました』はもう無価値、価値ある実績とは」**という論が伸びている。AIで誰でも作れる時代に"作った"だけでは差別化にならない、という主張。
- **なぜ今**：Claude Codeが5週間で30本超リリース、ユーザー層がエンジニア外（コンサル・マーケ・経営企画）に拡大。「誰でも作れる」が現実化し、実績の定義が問われ始めた。出典: [note あいすけ氏](https://note.com/suke_ai_code/n/n1b4e3ef24d80) / [note かりん氏](https://note.com/aikatsuyou_karin/n/nb365e83b1c11)
- **競合度**：「Claude Code入門/個人開発チュートリアル」は**飽和**。「作った後の価値・使われ続ける実績」論は**穴場**で、かつ伸びている。
- **強みの乗せ方**：E1が最強の反証＝「個人の習作」でなく「**実際に社内で使われ、要望が来て育ち続けている業務システム**」。要件定義→導入→運用まで1人。"使われている"こそ価値、という主張に一次情報で乗れる。
- **タイトル案**：「『AIでアプリ作れた！』で止まる人と、使われ続ける人の差｜実務で1人リプレイスして分かった"本当の実績"」
- **賞味期限**：しばらく使える（ポジショントーク系で寿命長め）。

### 【キャリア / 集客】⑤ AI時代、未経験からエンジニアは現実的か（生存戦略）
- **何がホット**：「AIが台頭した今、未経験からエンジニアは目指せるのか」論。**「何もできないから教えてもらえる時代は終わった」「教えなくてもAIを相棒に動ける人が求められる」**へ採用基準がシフト。
- **なぜ今**：若手エンジニア雇用減のデータ（①参照）と、未経験エンジニア過多の現実。noteでも「2026年の生存戦略を本音で」系が読まれている。出典: [note kou氏](https://note.com/awesome_engineer/n/nf6c5981b486b) / [note KAI氏](https://note.com/miyabi5432/n/nd1cfb47564ba) / [Qiita](https://jobs.qiita.com/junior-engineer-overflow/)
- **競合度**：一般論の「未経験はやめとけ/いける」は**飽和**。「複数業界を渡り歩いて辿り着いた×AIを相棒に動けた当事者の生存戦略」は**穴場**。
- **強みの乗せ方**：E8（メーカー系現場→生保営業→SES→IT、20代で転々）＋E1（その自分がAIで実務リプレイス）。「回り道してもAIを武器にすれば戦える」という等身大の希望＝売れる型A（経験のリアル型）に直結。集客で母数を集めL2/L3へ送る動線。
- **タイトル案**：「20代で4回転職した僕が、AI時代に"未経験からエンジニア"を本気で考える｜今から目指すなら何が必要か」

### 【お金 / 集客→有料】⑥ 20代一人暮らしの新NISA・節約のリアル（2027年改正前）

- **なぜ今**：改正前の今が"見直し"を促すタイミング。物価高で固定費見直し・自炊の関心も継続。
- **競合度**：**完全レッドオーシャン**（証券会社・FP記事が大量）。当ブランドが正面から攻めるのは不利。
- **強みの乗せ方（要注意）**：⚠️**experiences.mdに投資・節約の一次情報がまだ無い**（"まだ無い"欄）。等身大の数字・失敗談が無いと差別化できず勝てない。**推さない**。書くなら先に発信者から「自分の積立額/暗号資産の運用・失敗・固定費の実数」をヒアリングしてから。AIと家計の交差点（③）の方が今は勝ち目がある。
- **タイトル案（素材が揃ったら）**：「20代一人暮らしエンジニアの新NISA設定、全部見せます｜固定費はAIで見直した」
- **賞味期限**：2027年改正までが追い風。ただし素材待ち＝今は保留。

## 🏆 次に書くなら、これ TOP3（2026-06-29時点）

1. **① バイブコーディングの「修正地獄」を実務目線で（L3/有料）**
   - 理由：話題の絶頂＋幻滅期入りの二面性で需要が立っている今がピーク。入門解説は飽和だが「作った後どう死なないか」は穴場。E1/E2/E3が直結し、売れる型A（経験のリアル）×B（ノウハウ抽出）に綺麗にはまる。この発信者しか書けない一次情報の塊。

2. **④「アプリ作りました」はもう無価値論への当事者反証（L3/集客→有料）**
   - 理由：note内で現在進行形で伸びている論で流入が見込める。発信者の「使われ続けている実務システム」がそのまま最強の反証＝指名買いされる視点・思想型(C)の入口。①と内部リンクで回遊させると強い。

3. **③ ChatGPT家計・資産管理機能をエンジニア目線で検証（AI×お金/有料）**
   - 理由：5月リリースの新機能×日本未提供で「先取り解説」の窓が今開いている。AI活用と投資・資産形成という収益2本柱が交わる唯一のネタ。E2（検算）の一次情報で「作る側だから言える注意点」が差別化になる。⑥（節約/NISA）は素材不足で今は勝てないので、お金レーンはまず③で攻めるのが正解。

> 補足：⑥（NISA・節約）と⑦（AI比較L1）は需要は大きいが、⑥は発信者の投資/節約の一次情報待ち、⑦は超レッドオーシャンで集客割り切り用。**有料の本命は①④③**（＝AI実務×経験のリアル）に寄せるべき。
