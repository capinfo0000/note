# knowledge — ナレッジ蓄積（使うほど賢くなる箱）

動画でいう「Obsidian連携」と同じ役割。過去の学びをここに溜め、AI社員が毎回参照することで
「この発信者専用」に進化していく。**このフォルダ＝あなた専用AIの記憶**。

> Obsidianで開きたい場合は、このリポジトリのフォルダをそのまま「Vaultとして開く」だけでOK。

## ファイル
| ファイル | 中身 | 主に使う社員 |
|---|---|---|
| `results.md` | どの記事/タイトルが売れた・スベったか＋学び | researcher, planner |
| `swipe-file.md` | 刺さったタイトル・フック・言い回しのストック | planner, writer, promoter |
| `reader-voice.md` | 読者の声・質問・コメント・リアルな悩み | researcher, planner |
| `lessons.md` | editorの繰り返し指摘・やりがちなミス | writer, editor |

## 更新ルール（蓄積の習慣）
- 記事を1本出したら → `results.md` に結果を追記（数字が出る前でも「公開した」事実と仮説を記録）
- 反応が来たら → `reader-voice.md` に読者の声を追記
- 良い表現が書けたら → `swipe-file.md` にストック
- editorが同じ指摘を繰り返したら → `lessons.md` に追記

※ここにも個人情報（本名・会社名・住所・電話・メール・給料）は書かない。
